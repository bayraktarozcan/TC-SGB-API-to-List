About

What is TC-SGB-API-to-List?

An open-source Python pipeline that fetches Indicators of Compromise (IoCs) from T.C. Siber Güvenlik Başkanlığı's threat intelligence API, enriches them with contextual data, and distributes them in 16 industry-standard formats for SIEM, SOAR, and threat intelligence platforms.

Collect

Fetch IoCs from T.C. Siber Güvenlik Başkanlığı's API with automatic authentication, pagination, and rate limiting. Supports IPv4, IPv6, domain, URL, and hash indicators.

Enrich

Deduplicate, validate, and enrich IoCs with threat context. Apply confidence scoring, geo-location tagging, and threat actor attribution.

Distribute

Export to 16 formats including NextDNS, AdGuard, Pi-hole, dnsmasq, Unbound, RPZ, and more. Ready for any SIEM, SOAR, or TIP platform.

Architecture

Pipeline Architecture

A modular pipeline design with clear separation of concerns for reliability and extensibility.

1

Authentication

Secure OAuth2 authentication with T.C. Siber Güvenlik Başkanlığı API. Automatic token refresh and credential caching.

2

Fetch

Paginated IoC retrieval with retry logic. Handles 478K+ indicators across 5 sources.

3

Normalize & Deduplicate

Standardize IoC formats, remove duplicates, and validate against threat intelligence schemas.

4

Enrich

Add threat context: confidence scores, geo-tags, threat actor attribution, and malware family mapping.

5

Export

Generate 16 output formats in parallel. Ready for SIEM, SOAR, TIP, and manual analysis.

Quick Start

Get Started in 4 Steps

Follow these steps to start collecting IoCs from T.C. Siber Güvenlik Başkanlığı's API in minutes.

1

Clone the Repository

$ git clone https://github.com/bayraktarozcan/TC-SGB-API-to-List.git
$ cd TC-SGB-API-to-List
2

Install Dependencies

$ pip install -e .
3

Configure API Credentials

$ cp .env.example .env
# Edit .env with your API credentials
4

Run the Pipeline

$ tc-sgb fetch
# IoCs will be exported to ./output/ directory
