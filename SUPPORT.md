# Support

## Where to get help

- **Bugs and feature requests** — open a [GitHub issue](https://github.com/bayraktarozcan/TC-SGB-API-to-List/issues).
- **Security vulnerabilities** — **do not** open a public issue; follow
  [SECURITY.md](SECURITY.md) (GitHub private vulnerability reporting).
- **How to use the tool** — start with the [README](README.md); build and test
  instructions are in [CONTRIBUTING.md](CONTRIBUTING.md).

## Expectations

This is an open-source project maintained on a best-effort basis. There is no
formal support SLA. We aim to respond to issues and pull requests promptly, but
response times are not guaranteed.

## Before opening an issue

1. Check the [README](README.md), [CHANGELOG](CHANGELOG.md), existing issues,
   and pull requests for a known answer.
2. Run the project's quality checks (see `AGENTS.md`) to confirm your
   environment is sane.
3. Include: command used, expected vs. actual output, environment details
   (Python version, OS), and a minimal reproduction if possible.

# Destek

## Nasıl yardım alınır

- **Hatalar ve özellik istekleri** — bir [GitHub sorunu](https://github.com/bayraktarozcan/TC-SGB-API-to-List/issues) açın.
- **Güvenlik açıkları** — herkese açık bir sorun açmayın; [SECURITY.md](SECURITY.md) dosyasındaki (GitHub özel güvenlik açığı bildirimi) yönergeleri izleyin.
- **Araç nasıl kullanılır** — [README](README.md) ile başlayın; derleme ve test talimatları [CONTRIBUTING.md](CONTRIBUTING.md) dosyasındadır.

## Beklentiler

Bu, gönüllülük esasına dayalı olarak bakımı yapılan açık kaynaklı bir projedir.
Resmi bir destek SLA'sı yoktur. Sorun ve pull request'lere hızlıca yanıt vermeyi
hedefliyoruz ancak yanıt süreleri garanti edilmez.

## Sorun açmadan önce

1. Bilinen bir yanıt için [README](README.md), [CHANGELOG](CHANGELOG.md), mevcut
   sorunları ve pull request'leri inceleyin.
2. Ortamınızın sağlıklı olduğunu doğrulamak için projenin kalite kontrollerini
   (`AGENTS.md`) çalıştırın.
3. Kullandığınız komutu, beklenen ve gerçekleşen çıktıyı, ortam ayrıntılarını
   (Python sürümü, işletim sistemi) ve mümkünse asgari bir yeniden üretimi ekleyin.
